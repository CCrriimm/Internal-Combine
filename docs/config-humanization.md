# Config and humanized aim

Persistent preferences use `%LOCALAPPDATA%/Comet/BloodStrike/config.bin`. Session IPC remains `ipc/cfg.bin` plus shared memory. If LOCALAPPDATA is unavailable, persistent preferences fall back to `ipc/settings.bin`. On first use, a valid old IPC config is migrated; an existing invalid/unreadable persistent file is preserved until the user explicitly presses Save. Changes auto-save, manual Save writes immediately and Settings displays pending/saved/error status. Failed writes leave the dirty state set for retry.

Saved preferences omit menu-open/exit flags and one-shot apply commands. Loading clears those commands and opens the menu for the new session. Theme and Reduced Motion use tagged reserved padding. Bone=Random is retained; non-finite/range-invalid floats are normalized. The former unused FOV float now stores Human smoothing at the same serialized offset; invalid legacy values migrate to 0.5. The binary config remains 160 bytes with the existing version. Skin Inventory remains in its separate file.

When Humanize is enabled, aim uses 3–8 normalized direction nodes, bounded angular curvature, Catmull-Rom interpolation through the nodes and smooth temporal easing. Human smoothing controls path duration (0.04 + 0.20 × value seconds); the existing Smooth slider still controls camera tracking. Small target movement updates the path endpoint continuously; a completed path follows that endpoint without restarting each frame. Target changes, space changes, long gaps and large direction jumps rebuild from the camera's current heading. Releasing aim, losing candidates or disabling Humanize clears the path. Independent per-frame camera jitter is removed. Prediction and existing target filters are evaluated before the humanized path.

Validation: 109 offline tests pass, including a native MSVC harness extracting actual LoadCfg/SaveCfg functions and replacing IO with in-memory storage (no real user config is written). Config assertions cover migration, reload, session-command stripping, UI preferences, Random bone, corrupt-file preservation, explicit replacement, failed-write retry and finite-value handling. Nine path tests cover nodes/endpoints, progression, duration, continuity, target/space reset, disabled mode and stutters. Release packed EXE build succeeds. Live game feel and rendered layout have not been validated.
